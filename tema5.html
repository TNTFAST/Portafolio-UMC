Tema 5: Enfoque y utilidad de las bases de datos

Proyecto: Base de datos para gestionar el inventario de una tienda

Una base de datos es un sistema organizado para almacenar y gestionar información de manera estructurada que facilita el acceso y la manipulación de los datos. Este es fundamental porque permite una gestión eficiente y organizada de la información, lo que mejora la toma de decisiones y la productividad de la empresa.

En una tienda se necesita organizar la información de sus productos, categorías, proveedores y movimientos de inventario. Una base de datos relacional permite guardar estos datos de forma ordenada, reducir la repetición de información y facilitar las búsquedas y consultas.

Diseño de la base de datos

La base de datos se organiza en cuatro tablas relacionadas:

  • Categorías: registra los tipos de productos.
  • Proveedores: guarda los datos de quienes suministran los productos.
  • Productos: registra el nombre, precio y existencias de cada producto.
  • Movimientos: almacena las entradas y salidas de productos.

Las relaciones entre las tablas son las siguientes:

  • Una categoría puede tener muchos productos.
  • Un proveedor puede suministrar muchos productos.
  • Un producto puede tener varios movimientos de inventario.

Creación de las tablas en SQL

El siguiente ejemplo muestra cómo crear las tablas y relacionarlas mediante claves primarias y foráneas: 

CREATE TABLE Categorias (
    id_categoria INT PRIMARY KEY,
    nombre VARCHAR(50) NOT NULL
);

CREATE TABLE Proveedores (
    id_proveedor INT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    telefono VARCHAR(20)
);

CREATE TABLE Productos (
    id_producto INT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    id_categoria INT NOT NULL,
    id_proveedor INT NOT NULL,
    precio DECIMAL(10, 2) NOT NULL,
    existencias INT NOT NULL DEFAULT 0,
    FOREIGN KEY (id_categoria) REFERENCES Categorias(id_categoria),
    FOREIGN KEY (id_proveedor) REFERENCES Proveedores(id_proveedor)
);

CREATE TABLE Movimientos (
    id_movimiento INT PRIMARY KEY,
    id_producto INT NOT NULL,
    fecha DATE NOT NULL,
    tipo VARCHAR(10) NOT NULL,
    cantidad INT NOT NULL,
    FOREIGN KEY (id_producto) REFERENCES Productos(id_producto),
    CHECK (tipo IN ('Entrada', 'Salida')),
    CHECK (cantidad > 0)
);

Instrucciones de uso

  1. Crear las tablas en un gestor de bases de datos, como MySQL, PostgreSQL o SQLite.
  2. Registrar las categorías y los proveedores antes de agregar los productos.
  3. Ingresar cada producto con su categoría, proveedor, precio y cantidad disponible.
  4. Registrar las entradas y salidas de productos en la tabla de movimientos.
  5. Consultar los datos para conocer las existencias, buscar productos y revisar el inventario.

Con esta base de datos se pueden responder preguntas como:

  • ¿Qué productos pertenecen a cada categoría?
  • ¿Cuántas unidades quedan disponibles de cada producto?
  • ¿Qué productos tienen pocas existencias?
  • ¿Cuál es el valor total del inventario?

Estas preguntas pueden responderse con consultas SQL o mediante el uso de hojas de cálculo porque ofrecen una visión rápida y flexible de los datos.

Hoja de cálculo: clasificación y tabulación

Los datos de los productos también se pueden organizar en una hoja de cálculo, como Excel o Google Sheets. La siguiente tabla muestra un ejemplo:

ID Producto Categoría Proveedor Precio Existencias Valor del inventario
1 Cuaderno Papelería Suministros ABC 2,50 40 100,00
2 Lápiz Papelería Suministros ABC 0,50 100 50,00
3 Mochila Accesorios Distribuidora Norte 25,00 8 200,00

Para calcular el valor del inventario de cada producto, se multiplica el precio por la cantidad disponible. Si el precio está en la columna E y las existencias en la columna F, se puede usar esta fórmula: 

=E2*F2

Clasificación: ordenar los productos por nombre, categoría o cantidad disponible. También se pueden aplicar filtros para mostrar productos de una categoría específica o aquellos con pocas existencias.

Tabulación: crear una tabla dinámica que agrupe los productos por categoría y muestre cuántos productos hay, cuántas unidades están disponibles y cuál es el valor total del inventario.

Control de los datos

  • No repetir el identificador de un producto dentro de la tabla.
  • Completar los campos obligatorios, como el nombre y el precio.
  • Verificar que cada producto esté asociado a una categoría y a un proveedor existentes.
  • Ingresar precios y cantidades válidos, evitando valores negativos.
  • Registrar cada movimiento con su fecha, tipo y cantidad.
  • Comparar periódicamente las existencias registradas con el inventario físico.
  • Revisar que las fórmulas de la hoja de cálculo estén aplicadas a todas las filas.

Utilidad de la base de datos

Esta base de datos facilita la búsqueda y actualización de información, ayuda a controlar las entradas y salidas de productos y permite identificar artículos con pocas existencias. La hoja de cálculo complementa el sistema al presentar los datos clasificados y resumidos en tablas y gráficos, lo que facilita la toma de decisiones y la planificación del inventario.
