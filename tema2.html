Tema 2: Lenguaje de programación

La palabra informática proviene de la contracción de información y automática. Es la ciencia que estudia el tratamiento automático de la información mediante sistemas computacionales. Esta misma ha evolucionado a lo largo del tiempo, desde los primeros sistemas de procesamiento de datos hasta las modernas aplicaciones de inteligencia artificial y análisis de grandes volúmenes de información.

Historia y su evolución

Década de 1940 - Primeros lenguajes de programación

Los primeros lenguajes de programación eran muy básicos y estaban diseñados para ser utilizados en computadoras específicas. Estos lenguajes permitían a los programadores escribir instrucciones directamente en código máquina, lo que requería un conocimiento profundo del hardware.

Década de 1950 - Lenguajes de alto nivel

Se desarrollaron lenguajes de programación de alto nivel, como Fortran y COBOL, que permitían a los programadores escribir instrucciones más comprensibles y portables. Estos lenguajes facilitaron la creación de programas más complejos y la colaboración entre programadores.

Década de 1960 - Lenguajes estructurados

Surgieron lenguajes estructurados, como Algol y Pascal, que promovían la organización del código en bloques y funciones. Esto mejoró la legibilidad y mantenibilidad del código, facilitando el desarrollo de software más grande y complejo.

Década de 1970 - Lenguajes orientados a objetos

Se introdujeron lenguajes orientados a objetos, como Smalltalk y C++, que permitían modelar el mundo real mediante objetos y clases. Este enfoque facilitó la reutilización del código y la creación de aplicaciones más modulares.

Década de 1980 - Lenguajes de scripting

Aparecieron lenguajes de scripting, como Perl y Tcl, que se utilizaban para automatizar tareas y crear aplicaciones web. Estos lenguajes eran más fáciles de aprender y permitían a los programadores desarrollar soluciones rápidamente.

Década de 1990 - Lenguajes web

Con la popularización de Internet, surgieron lenguajes de programación web, como JavaScript y PHP, que permitían crear sitios web interactivos y dinámicos. Estos lenguajes se convirtieron en herramientas esenciales para el desarrollo de aplicaciones en línea.

Década de 2000 - Lenguajes modernos y frameworks

Se desarrollaron lenguajes modernos, como Python y Ruby, que ofrecían sintaxis más sencilla y legible. Además, surgieron frameworks y bibliotecas que facilitaban el desarrollo de aplicaciones web y móviles, acelerando el proceso de creación de software.

Década de 2010 - Lenguajes para inteligencia artificial y big data

Con el auge de la inteligencia artificial y el análisis de grandes volúmenes de datos, surgieron lenguajes especializados, como R y Julia, que permitían realizar análisis estadísticos y modelado de datos. Estos lenguajes se convirtieron en herramientas clave para científicos de datos y analistas.

Por lo tanto, un lenguaje de programación es un conjunto de reglas y símbolos que permiten a los programadores escribir instrucciones para que una computadora realice tareas específicas. Existen muchos lenguajes de programación, cada uno con sus características y usos particulares, los cuales se pueden clasificar en diferentes tipos, como lenguajes de bajo nivel y lenguajes de alto nivel.

Lenguaje de bajo nivel

Los lenguajes de bajo nivel están más cerca del lenguaje que entiende la computadora. Son difíciles de leer y escribir para los humanos, pero permiten un control más directo sobre el hardware. Un ejemplo es el lenguaje ensamblador.

Lenguaje de alto nivel

Los lenguajes de alto nivel son más fáciles de entender y usar para los programadores. Se parecen más al lenguaje humano y permiten crear programas complejos de manera más sencilla. Ejemplos de lenguajes de alto nivel son Python, Java y C++.

Lenguajes de programación web

Se utilizan para crear sitios web y aplicaciones en línea. Ejemplos: HTML, CSS, JavaScript, Python y PHP.

Lenguajes de programación científica

Se emplean para realizar cálculos complejos y análisis de datos. Ejemplos: MATLAB y R.

Lenguajes de programación de videojuegos

Se usan para desarrollar juegos y simulaciones interactivas. Ejemplos: C# y UnityScript.
